# Назначение руководителя проектно-конструкторского отдела

Проект для проведения назначения **Иванюк В.С.** ведущим инженером-конструктором
и руководителем проектно-конструкторского отдела ООО «АльденаГрупп».

## С чего начать
1. Прочитайте `CLAUDE.md` — карта проекта и правила работы.
2. Проверьте `00_Исходные_данные/Данные_проекта.md` — все реквизиты и ФИО.
3. Идите по `ROADMAP_внедрения.md` — пошаговый план от подписания до работы отдела.

## Состав пакета
- **01_Кадровые_документы** — представление, приказы, должностная инструкция,
  допсоглашение, лист ознакомления (легитимизация должности).
- **02_Положение_об_отделе** — устав отдела: задачи, функции, полномочия, подчинение.
- **03_Внедрение_и_коллектив** — план 30/60/90, сценарий представления коллективу,
  протокол собрания, план обучения новичков.
- **04_Шаблоны_управления_отделом** — табель, график отпусков, журналы задач и
  проверки чертежей, реестр объектов, форма отчёта.
- **05_Регламент_конструкторов** — готовый Регламент КМД.

## Получить готовые `.docx`
```
python scripts/build_docx.py
```
Файлы появятся в `_build/docx/`. Исходники — `.md` рядом с каждым документом;
после правок `.md` запускайте генератор заново.

## Порядок подписания (коротко)
Представление → приказ о переводе → приказ о руководстве отделом → допсоглашение →
утверждение ДИ и положения → лист ознакомления → представление коллективу.
