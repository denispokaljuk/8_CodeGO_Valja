# Назначение начальника проектно-конструкторского отдела

Проект для перевода **Иванюк В.С.** на должность **начальника
проектно-конструкторского отдела** ООО «АльденаГрупп». Наименование должности —
по выпуску 39 ЕКСД (пост. Минтруда и соцзащиты РБ от 23.02.2024 № 9).

## С чего начать
1. Прочитайте `CLAUDE.md` — карта проекта и правила работы.
2. Проверьте `00_Исходные_данные/Данные_проекта.md` — все реквизиты и ФИО.
3. Идите по `ROADMAP_внедрения.md` — пошаговый план от подписания до работы отдела.

## Состав пакета
- **01_Кадровые_документы** — представление, приказы (перевод, создание отдела,
  надбавка, штатное расписание), полный контур аттестации (положение, приказ о
  проведении, характеристика-отзыв, приказ по итогам), должностная инструкция,
  допсоглашение, лист ознакомления, информационное письмо начальнику отдела.
- **02_Положение_об_отделе** — устав отдела: задачи, функции, полномочия, подчинение.
- **03_Внедрение_и_коллектив** — план 30/60/90, сценарий представления коллективу,
  протокол собрания, план обучения новичков, чек-лист контрольных точек 30/60/90.
- **04_Шаблоны_управления_отделом** — табель, график отпусков, рабочий журнал
  отдела (объекты, задачи, нормоконтроль + чек-лист по Регламенту КМД),
  акт приёма-передачи дел, памятка типовых замечаний нормоконтроля.
- **05_Регламент_конструкторов** — Регламент КМД, редакция 2026: порядок работы
  над объектом, структура папок, Advance Steel, оформление, раскрой и файлы для
  производства, передача в CRM, обязательный чек-лист.

## Получить готовые `.docx`
```
python scripts/build_docx.py
```
Файлы появятся в `_build/docx/`. Исходники — `.md` рядом с каждым документом;
после правок `.md` запускайте генератор заново.

## Порядок подписания (коротко)
Представление → аттестация (приказ о проведении → характеристика-отзыв →
протокол комиссии → приказ по итогам) → заявление работника → утверждение
штатного расписания → приказ о переводе → приказ о создании отдела →
приказ о надбавке → допсоглашение → утверждение ДИ и положения →
лист ознакомления + информационное письмо → акт приёма-передачи дел →
представление коллективу.

## Даты в документах
Все конкретные даты в документах намеренно оставлены пустыми в формате
`«___» __________ 2026 г.` — число и месяц проставляются от руки при подписании.
