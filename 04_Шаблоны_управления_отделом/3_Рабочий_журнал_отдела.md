# Рабочий журнал проектно-конструкторского отдела

Единый журнал: объекты, распределение задач и нормоконтроль в одной таблице.
Ведёт начальник отдела (Иванюк В.С.). Одна строка — одна задача по объекту,
от постановки до выпуска. Заводить отдельные журналы не требуется.

**Приоритет:** проставляется от руки — `1`, `2`, `3` … (1 — самый срочный).
Приоритеты согласуются с заместителем директора и меняются по ходу работы.
**Статус:** `в очереди` → `в работе` → `на проверке` → `выпущено`
**Нормоконтроль:** `прошёл` / `не прошёл` (заполняется на этапе «на проверке»)

## Как вести журнал
1. **Объект пришёл** — завести строку: объект, состав работ, срок; статус «в очереди».
2. **Проставить приоритет** — от руки, цифрой. При изменении приоритета старую
   цифру зачеркнуть, рядом написать новую (карандашом — просто переписать).
3. **Задача роздана** — вписать исполнителя и дату начала; статус «в работе».
   Задачи берутся в работу по возрастанию приоритета.
4. **Чертёж сдан на проверку** — статус «на проверке», пройти чек-лист ниже.
5. **Нормоконтроль:**
   - всё в порядке → в столбце «Нормоконтроль» поставить **прошёл**, статус «выпущено», дата и подпись;
   - есть замечания → **не прошёл**, кратко записать замечания и дату повторной сдачи, статус остаётся «на проверке».
6. Повторная сдача — отметку в столбце «Нормоконтроль» переписать на «прошёл»
   после устранения замечаний.
