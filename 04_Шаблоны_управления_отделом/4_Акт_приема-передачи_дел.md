## 2. Документация и архив
| № | Что передаётся | Где находится | Отметка о передаче |
|---|---|---|---|
| 1 | Архив выпущенной документации КМД | сетевой ресурс `\\192.168.1.2\объекты` (диск `Z:`), каталог по году и шифру объекта |  |
| 2 | Исходные данные по объектам (КМ, КЖ, АР, ТЗ) | папка `ТЗ` в каталоге объекта: `Z:\<год>\<шифр> <объект>\ТЗ\` |  |
| 3 | Договоры по объектам | в корне каталога объекта: `Z:\<год>\<шифр> <объект>\` |  |
| 4 | Регламент оформления чертежей КМД (контрольный экземпляр) | ____________________ |  |

> **Структура сетевого архива.** Корень — `\\192.168.1.2\объекты` (подключается как
> диск `Z:`). Далее каталог года, внутри — каталоги объектов, начинающиеся с шифра.
> В корне каталога объекта лежит договор, исходные данные — в подпапке `ТЗ`.
>
> Пример (объект 950-26 «Савушкин продукт»):
> - каталог объекта — `Z:\2026\950-26 Савушкин продукт - подряд (площадкаи 3шт., 30 тонн)\`
> - договор — `950-26 Договор (подряд) - Савушкин продукт - Барановичи, площадки 3шт.docx`
> - исходные данные — `Z:\2026\950-26 Савушкин продукт - подряд (площадкаи 3шт., 30 тонн)\ТЗ\`
